Which token?
  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → {{REPO}}.
  3. Permissions → Repository: Actions: Read and write. Nothing else.

The token only goes to api.github.com. With “Remember” on, it's kept in this browser's local storage and nowhere else.
